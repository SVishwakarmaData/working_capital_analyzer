# Working Capital Analyzer

Calculates the Cash Conversion Cycle (DIO + DSO − DPO) for 3
steel-sector companies to compare how efficiently each turns
inventory and receivables into cash.

**Tech:** Python, yfinance, pandas, matplotlib

**Companies:** Tata Steel, JSW Steel, SAIL — chosen because CCC
needs real inventory and AR/AP, which banks don't have.

**Run it:**
```
pip install yfinance pandas matplotlib
jupyter notebook working_capital_analyzer.ipynb
```
